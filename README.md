# NotabilityEditor 0.7.7-Beta

## 本次新增与改进

- **独立主页与本机笔记库**：新增首页、全部笔记和分类导航，支持当前列表搜索、最近打开与名称排序、封面及紧凑列表切换。打开原文件或导入副本均可从主页进入，导入及新建笔记统一收纳到本机笔记库。
- **多选与批量整理**：支持复选框、Ctrl/Shift 多选、Ctrl+A 全选当前结果（包含屏幕外笔记）、空格切换及 Esc 取消。批量分类提供进度、取消、失败保留选择与重试。
- **分类管理**：新建分类采用中文弹窗，支持名称提示、实时重名和有效字符校验。库内笔记按分类整理文件夹，外部笔记保留原位置。
- **分类数据持久化**：分类名称、笔记归属、原路径与移动历史保存到固定用户数据文件；自动迁移旧记录，支持备份恢复和写入失败回滚，更新程序后继续使用。
- **删除笔记**：底部增加单选和多选删除入口，确认后移至系统回收站；明确提示外部原文件的处理范围，失败时保留文件与记录。
- **遮字胶带**：新增原生胶带工具，支持九种图案、颜色和宽度设置，以及选择移动、擦除、跨页和撤销重做。临时揭开只影响当前阅读，保存、缩略图和 PDF 导出继续保留遮盖。
- **自定义纸张颜色**：新建笔记时可为现有空白、横线和点阵模板选择背景颜色，并写入原生纸张数据。
- **全屏与浏览**：F11 切换全屏编辑，Esc 退出；支持从纸张外侧灰色区域拖动浏览，保留工具状态和阅读位置。
- **无缝页面与智能插点**：新增页面无缝衔接开关，支持连续跨页绘制、擦除及整次操作撤销。智能插点开关为新笔迹生成平滑曲线，保留端点、尖角与跨页边界。
- **浏览器触控工作台**：新增本机服务与触控界面，支持 NTB 打开、新建、笔迹编辑、插入图片、自动快照、保存下载及 PDF 导出；当前通过浏览器运行，尚未提供原生 Android 安装包。
- **原生笔记兼容性**：改进多分组纸张与真实尾页映射，补充原生线段、曲线、箭头、多边形和椭圆的显示及擦除，修复相关页面复制、重排和图片跨页移动问题。旧式纸张纹理以底色近似预览，原设置继续保留。
- **保存体验与异常恢复**：改进现有后台保存流程，保存期间可以继续编辑，重复保存合并排队；成功后保留画布、缩放及撤销记录。新增本地恢复快照，异常退出后可恢复尚未保存的编辑。
- **稳定性与性能**：修复退出阶段的访问冲突和重叠笔迹擦除后恢复问题；优化文档切换、缓存释放、大文件流式处理及可见页面优先渲染。

NotabilityEditor 是基于 GitHub 上 NotabilityViewer 预览能力扩展开发的跨平台笔记软件，提供笔记阅读、手写批注、图片与页面管理，以及 NTB 保存和 PDF 转换。

项目面向 Notability 的 **NTB** 和 **NOTE** 格式。完整图形编辑入口支持 NTB 编辑与保存、NOTE 阅读与导出、新建 NTB、导入 PDF 和导出 PDF；触控工作台当前只适配 **NTB**。本项目与官方 Notability 客户端无隶属关系。

## 主要功能

- 打开 NTB 笔记，查看原生笔迹、内嵌 PDF、图片及文字。
- 新建 NTB 笔记，选择纸张尺寸与模板。
- 画笔、荧光笔、整笔与局部橡皮擦、矩形与自由形状选取、图片工具和漫游。
- 在图片上方书写和标注，移动选中笔迹，使用撤销与回退。
- 管理页面、阅读位置、缩放和工具偏好；可写范围由格式结构校验决定。
- 导入 PDF 创建笔记，导出 PDF；NOTE 格式以阅读与导出为主。
- 主页支持历史打开记录、笔记分类、搜索、新建、打开和导入；主页与编辑界面分别维护。
- 触控编辑自动生成恢复快照，返回主页时写入 NTB；正常退出先完成写入，下次打开前恢复未完成的快照。

## 启动

建议使用 Python 3.11，并在虚拟环境中安装依赖：

```shell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

完整图形编辑入口：

```shell
.venv\Scripts\python main.py
```

连接本地处理后端的触控工作台：

```shell
.venv\Scripts\python tablet_server.py
```

服务默认只监听本机 `127.0.0.1:8767`，启动后自动打开主页。可使用 `--port` 修改端口、`--no-browser` 关闭自动打开浏览器，或用 `--data-dir` 指定工作副本与快照目录。不要直接双击触控 HTML 文件，真实 NTB 处理需要通过此服务运行。

`INSTALL.bat` 是安装与编译入口，调用 `deploy_windows.ps1` 安装依赖、构建和注册应用。程序的安装、注册和更新继续使用统一版本比较，阻止旧程序覆盖新程序。

## 主页与编辑页

完整图形入口 `main.py` 默认显示主页。主页只显示“文件、设置、帮助”三个菜单，不显示阅读工具栏、笔迹编辑工具栏和页面侧栏。

- **首页**：左右两栏布局，左侧包含搜索、首页、笔记与分类栏；右侧上栏为“打开笔记、导入 PDF、新建笔记”，下栏显示最近打开的笔记封面卡片。主页沿用编辑页的蓝色调。
- **笔记**：显示全部笔记，选中分类后只显示该分类中的笔记；沿用既有最近文件记录，已有历史无需重新导入。
- **分类与搜索**：新建分类，将选中笔记归入分类；右键分类可以重命名或移除分类。搜索匹配笔记名称、分类和路径。外部笔记分类仅修改记录，库内笔记同步整理分类文件夹。
- **笔记管理**：点击卡片右上角“⋯”或右键，菜单包含“重命名、删除笔记、更改分类、打开所属位置”。外部笔记额外提供“删除笔记记录”，只移除使用记录。默认分类为“未分类”，分类的新建、重命名和删除在左侧分类栏完成。
- **本机笔记库**：专属目录保存导入副本及新建笔记。直接打开的外部笔记仅记录原路径，重命名在原目录执行；文件不存在时隐藏记录，文件恢复后重新显示。无论库内还是外部笔记，“删除笔记”均弹窗显示实际路径，确认后将文件移入回收站并移除使用记录；回收失败时保留文件和记录。
- **分类文件夹**：笔记库按分类建立文件夹，新建与导入默认进入“未分类”。库内笔记更改分类时移动实际文件，并同步路径、阅读位置和移动记录；分类重命名或删除时一并整理所属笔记。外部笔记只更改分类记录，保持原文件位置。移动历史保存在笔记库索引的 `movement_history` 中，保留最近 1000 条。
- **新建笔记**：选择纸张和底页后进入编辑页，首次保存默认使用本机笔记库的独立目录，也可自行选择位置。
- **打开笔记**：直接打开原位置的 NTB / NOTE，保存 NTB 时写回该文件，不会自动移入笔记库。编辑会话按需在应用恢复目录保留一份原始素材基准，用于连续保存、撤销和异常恢复。NOTE 延续只读预览与导出行为。
- **导入笔记**：把 NTB / NOTE 复制到本机笔记库，再打开副本；不会覆盖来源文件。导入在后台执行，可以取消。
- **导入 PDF 生成笔记**：复用原有 PDF 转换流程，生成可编辑的 NTB 草稿，首次保存默认使用本机笔记库；原 PDF 保持不变。

打开或新建成功后进入原有编辑界面，继续使用现有菜单、工具栏和页面管理。通过“文件 → 返回主页”或 `Alt+Home` 返回；有修改时提示保存、放弃或取消，保存失败或取消保存时留在编辑页。

分类与笔记索引保存在 `%LOCALAPPDATA%/NotabilityEditor/home-library.json`，最近记录及阅读位置沿用用户设置，导入副本及新建笔记的默认位置为 `%LOCALAPPDATA%/NotabilityEditor/library/`，可以通过 `NE_LIBRARY_DIR` 指定其他目录。每次导入使用独立目录，同名笔记不会互相覆盖。清空历史打开记录不会删除笔记库索引或笔记文件。找不到的文件隐藏而不删除记录；重命名会同步更新记录和阅读位置。

兼容 NotabilityEditor 0.7.6-Beta 的最近文件及阅读位置记录，沿用原设置位置和数据字段。旧记录首次读取时加入笔记库索引，默认归入“未分类”，保留原路径、最近打开顺序、页码、缩放及滚动位置，不复制原始笔记。

## 编辑会话的保存与恢复

- 保存时捕获独立的编辑快照，后台生成并校验完整 NTB，成功后安全替换目标文件。保存期间仍可书写、选取、操作图片及撤销；新的修改保持未保存状态。
- 保存及另存为后继续使用当前画布，保留页码、缩放、滚动位置及撤销记录，无需重新打开笔记。连续保存始终从原始素材基准和累计编辑生成，避免重复写入图片或丢失已删除页面的撤销素材。
- 编辑完成后约两秒异步写入本地恢复快照，连续编辑会合并处理。首次快照或保存会复制一次原 NTB 作为会话基准；此副本会占用与原文件相近的磁盘空间，正常关闭会话后清理。
- 恢复数据默认位于 `%LOCALAPPDATA%/NotabilityEditor/recovery/`，可通过 `NE_RECOVERY_DIR` 修改。异常退出后，下次启动会提示恢复，也可选择“文件 → 恢复未保存的笔记…”，生成新的 NTB，不覆盖原文件。恢复成功并打开后清理对应快照。
- 普通保存通过状态栏提示完成；首次保存、另存为和写入恢复副本时显示文件位置。取消或失败时保留编辑与已有恢复快照。文件被外部修改时停止替换。

本地恢复快照与正式 NTB 保存相互独立。强制终止或断电无法执行退出收尾；尚未完成落盘的最后瞬间输入仍可能丢失。

## 触控工作台的数据流程

1. 首页通过设备文件选择器打开 `.ntb`，后台复制到独立工作目录，再调用原有格式解析器。源文件保持不变。
2. 界面加载真实页面、原生笔迹和底图。工具栏下排随当前工具变化，各工具保留自己的参数。
3. 完成一次编辑后立即更新浏览器恢复缓存；短暂合并连续操作后，将完整编辑快照原子写入后台磁盘。
4. 返回主页时自动把快照转成 NTB，无需询问保存。更多菜单中的“保存并退出”先保存全部待处理快照，再关闭后台；控制台正常退出也执行收尾。
5. 下次进入笔记前，处理未完成的快照。同一编辑会话可利用上一份基线补写较新的缓存；其他窗口的过期保存会被拒绝。
6. “保存笔记”提供真实 NTB 下载，“导出全部页面 PDF”调用共用 PDF 导出器。

后台工作副本与下载文件不同：自动保存写入工作副本，下载后由用户选择存放位置；浏览器不能静默覆盖文件选择器选中的原文件。断电或操作系统强制终止无法执行退出代码，已落盘快照留待下次恢复，尚未写入的最后瞬间输入不作无丢失保证。

默认运行数据位于项目根目录的 `.tablet-data/`，包含 NTB 工作副本、恢复快照和上一份基线。它们属于用户数据，排除在源码发布包外；不要作为缓存随意清理。删除首页笔记卡片仅移除本地笔记库索引，不删除最初选择的原始文件。

## 当前连接范围

触控工作台已接入本地 NTB 打开、新建、笔迹编辑、图片插入、自动快照、保存、下载和 PDF 导出。原有 NTB 图片与文字保持原生数据并作为受保护内容显示，可以在上面批注；当前连接层不提供这些既有对象的移动或删除。新插入图片保存为原生 NTB 图片事件，重新打开后也作为受保护内容显示。

新增与删除页面仅对已验证的纸张或逐页结构开放。原生页面复制、部分分组 PDF 的结构调整、已有笔记的模板替换，以及触控 PDF 导入尚未接入。完整图形入口中的既有功能仍保留。

当前触控界面通过本地服务运行，尚未生成原生 Android 安装包；本机服务不默认开放局域网访问。文件上限为 2 GB、解压内容上限为 4 GB，笔记最多 500 页和 200 万个笔迹采样点。大文件通过流式上传复制，笔记内容不发送到外部 AI 服务。

现有源码模块使用 `ne_` 文件名前缀。界面只处理展示、输入和调用，NTB 二进制解析及写回应放在格式层，连接层负责验证界面快照、映射稳定身份和调用共用引擎。

| 处理步骤 | 共用实现 |
| --- | --- |
| 读取 NTB 与资源 | `formats/ne_loader.py`、`formats/ne_ntb.py` |
| 原生笔迹与编辑模型 | `editing/ne_edits.py` |
| 保存会话、独立快照与异常恢复 | `editing/ne_save_session.py` |
| 页面能力与结构校验 | `pages/ne_page_access.py`、`formats/ne_pagewrite.py` |
| 生成新笔记 | `import_export/ne_newnote.py` |
| 原子写回原生事件 | `formats/ne_native.py`、`core/ne_safecommit.py` |
| 图片写入 | `images/ne_inserted_images.py` |
| 页面显示与 PDF 导出 | `rendering/ne_pdfview.py`、`import_export/ne_export.py` |

显示缓存不作为笔记底图写回。保存保留未知原生事件与资源；未知或未验证的破坏性结构操作会被阻止。后台 Qt 对象在同一线程中处理，避免跨线程访问渲染对象。
